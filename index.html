    03 — A sample of the style

    No eval(). No shortcuts.

    A real fragment from NexaBank — every money-moving operation runs inside a locked transaction.

    BankService.php
    // transfer() — row-locked, all-or-nothing
public function transfer($fromId, $toId, $amount) {
    $this->pdo->beginTransaction();
    try {
        $from = $this->lockAccount($fromId);
        $to   = $this->lockAccount($toId);

        if ($from['balance'] < $amount) {
            throw new InsufficientFundsException();
        }

        $this->debit($fromId, $amount);
        $this->credit($toId, $amount);
        $this->pdo->commit();
    } catch (Throwable $e) {
        $this->pdo->rollBack();
        throw $e;
    }
}

    06.6 — Debugging stories

    Real bugs, real fixes.

    Two issues found and fixed directly on this portfolio's own codebase.

    Mobile page cut off the "Let's Talk" button

    ProblemHorizontal scroll on phones and tablets pushed the nav CTA off-screen.
    InvestigationRan a Playwright sweep across six device widths, then a DOM scan flagging every element wider than the viewport.
    Root causeOnly <body> had overflow-x:hidden — <html> didn't, so the tech marquee and decorative background shapes still expanded the document's scrollable width.
    FixAdded overflow-x:hidden and max-width:100vw to <html> as well.
    ResultZero horizontal scroll confirmed from 375px to 1366px, 0 console errors.

    Light mode made panels unreadable

    ProblemThe nav, AI panel and certificate popups stayed visually dark while their text flipped to a dark color in Light mode.
    InvestigationAudited every panel background declaration across the stylesheet.
    Root causeAround two dozen hardcoded dark rgba() backgrounds that never adapted to the active theme.
    FixIntroduced theme-aware CSS custom properties for glass/tint surfaces and swapped every hardcoded value for one.
    ResultVerified legible, correctly-tinted panels in Dark, Light and Eye Comfort modes.
