01 — About

Engineering discipline, practiced in public.

I'm an undergraduate at SLIIT who treats every personal repo as a place to practice real engineering discipline — not just make something that works once. Most of my featured projects are deliberately framework-free: before I let React or Next.js abstract something away, I build it in plain JavaScript first, so I understand exactly what I'm trading for convenience.

Right now that means juggling a full course load with two internships at once — a Software Engineering role at EgoTechWorld and a Frontend Development role at CodeAlpha — plus three completed levels of a development internship at Codveda. Security and correctness aren't an afterthought: bcrypt hashing, CSRF tokens, prepared statements and row-locked database transactions show up throughout my work, including in a full banking-system rebuild with ACID-safe money movement.

03 — A sample of the style

No eval(). No shortcuts.

A real fragment from NexaBank — every money-moving operation runs inside a locked transaction.

BankService.php
// transfer() — row-locked, all-or-nothing
public function transfer($fromId, $toId, $amount) {
    $this->pdo->beginTransaction();
    try {
        $from = $this->lockAccount($fromId);
        $to   = $this->lockAccount($toId);

        if ($from['balance'] < $amount) {
            throw new InsufficientFundsException();
        }

        $this->debit($fromId, $amount);
        $this->credit($toId, $amount);
        $this->pdo->commit();
    } catch (Throwable $e) {
        $this->pdo->rollBack();
        throw $e;
    }
}
