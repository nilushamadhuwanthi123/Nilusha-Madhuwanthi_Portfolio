# Nilusha Madhuwanthi — Portfolio

Personal portfolio site — built from scratch, vanilla HTML/CSS/JS with a Three.js animated
background, no framework. Highlights the stack, the two concurrent internships, and seven
live-deployed personal projects.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-nilusha--madhuwanthi-16A34A?style=for-the-badge&logo=vercel&logoColor=white&labelColor=10120F)](https://nilusha-portfolio.vercel.app)

## Stack

- Vanilla HTML / CSS / JavaScript — no build step
- [Three.js](https://threejs.org/) for the animated wireframe/particle background
- IntersectionObserver for scroll reveals

## Structure

```
index.html   # markup + content
style.css    # design system (olive / obsidian / gold / silver palette)
script.js    # 3D background, typing effect, scroll reveals
```

## Run locally

Just open `index.html` in a browser — no dependencies, no build step.
